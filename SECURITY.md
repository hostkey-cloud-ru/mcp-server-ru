# Безопасность

Не создавайте публичные issue по уязвимостям. Пишите на hkadm@hostkey.ru
или через GitHub Security Advisories.

- Ключ только в `HOSTKEY_API_KEY`, не в коде и не в репозитории.
- Для ограниченного доступа — ключ на один сервер.
- Деструктивные операции по умолчанию выключены (`HOSTKEY_ALLOW_DESTRUCTIVE=0`).
- Если секрет утекает в ответ или лог — сообщите сразу.
